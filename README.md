# myhermes-fe

Frontend dashboard for MyHermes, built with React, TypeScript, Vite, and
Tailwind CSS.

## Requirements

- Node.js 20 or later
- npm

## Development

```bash
npm install
npm run dev
```

## Available Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm run preview` serves the production build locally.

## Branding

The current logo and favicon assets are sourced from the OneAuth frontend.
